## Honest status of the Sketchfab requirement

Sketchfab's `/v3/models/{uid}/download` endpoint returns **HTTP 401 Authentication credentials were not provided** without a personal Sketchfab API token, and no such token exists in the MR Studio handover documents. Therefore no Sketchfab binary was downloaded.

`assets/models/SCP173.glb` is a genuinely loadable glTF 2.0 binary produced by `tools/make_scp173_glb.py` (original procedural sculpture geometry), not a renamed Sketchfab file. It is the GLB the game actually loads.
