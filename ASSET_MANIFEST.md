## Honest status of the Sketchfab requirement

The Sketchfab v3 search endpoint was called for real with `q=SCP-173&downloadable=true&sort_by=-likeCount`. The popularity-ranked No.1 hit is recorded above. Sketchfab's `/v3/models/{uid}/download` endpoint returns **HTTP 401 Authentication credentials were not provided** without a personal Sketchfab API token, and no such token exists in the MR Studio handover documents. Therefore no Sketchfab binary was downloaded.

`assets/models/scp-173.glb` is now a genuinely loadable glTF 2.0 binary **repackaged from the real CC-BY 3.0 community statue by Yni Viar** (see the table above). `tools/gltf_to_glb.py` only embeds the upstream `.bin` and 3 PNGs into the GLB container — geometry and textures are unmodified. `tools/make_scp173_glb.py` remains available as an original-geometry generator, and the in-engine `buildSCP173()` procedural statue is kept strictly as an offline fallback.

**Mobile rebuild (2026-11-15):** the default in-game entity is now a procedural humanoid built directly in `js/main.js` `buildSCP173()` from `BoxGeometry` + `CylinderGeometry`. This removes any dependency on external textures for the creature's silhouette (the earlier mobile report of a "white block").

**Fix round (2026-11-15, `fix: flashlight, UI, fullscreen, raycast`):** the procedural entity was rebuilt as **121 parts** with `MeshStandardMaterial({ color: 0x777777, roughness: 0.9 })` — segmented legs/arms, five two-joint fingers per hand, ribcage, brow ridge, thick three-section neck, orange paint marks, cracks and exposed rebar, scaled to ~3.5 m so it does not clip the ceiling. An invisible `SCP173_HitProxy` mesh was added so the centre ray cannot slip between the 120 separate parts.

The real open-source `humanoid.glb` above downloads successfully and is wired up: append `?humanoid=1` to load it (concrete re-skin + 173 paint/neck overlay). It is **not** the default because CesiumMan is a textured, skinned, animated human in a uniform — using it directly would look nothing like a concrete SCP-173 statue, and `SkinnedMesh` raycasting is less reliable for the observation mechanic. `?glb=1` now loads the real Yni Viar `assets/models/scp-173.glb` through `prepareReal173()`; `?xbot=1` loads the three.js Xbot rig. Nothing here is a renamed or faked Sketchfab file.

Freesound preview audio and ambientCG textures are real downloaded open assets. Reuse terms are per-source (Freesound previews carry the individual sound's CC license; ambientCG is CC0; Three.js is MIT).
