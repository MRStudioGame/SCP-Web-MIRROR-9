## Honest status of the Sketchfab requirement

The Sketchfab v3 search endpoint was called for real with `q=SCP-173&downloadable=true&sort_by=-likeCount`. The popularity-ranked No.1 hit is recorded above. Sketchfab's `/v3/models/{uid}/download` endpoint returns **HTTP 401 Authentication credentials were not provided** without a personal Sketchfab API token, and no such token exists in the MR Studio handover documents. Therefore no Sketchfab binary was downloaded.

`assets/models/SCP173.glb` is a genuinely loadable glTF 2.0 binary produced by `tools/make_scp173_glb.py` (original procedural sculpture geometry), not a renamed Sketchfab file.

**Mobile rebuild (2026-11-15):** the default in-game entity is now a procedural humanoid built directly in `js/main.js` `buildSCP173()` from `BoxGeometry` + `CylinderGeometry`. This removes any dependency on external textures for the creature's silhouette (the earlier mobile report of a "white block").

**Fix round (2026-11-15, `fix: flashlight, UI, fullscreen, raycast`):** the procedural entity was rebuilt as **121 parts** with `MeshStandardMaterial({ color: 0x777777, roughness: 0.9 })` — segmented legs/arms, five two-joint fingers per hand, ribcage, brow ridge, thick three-section neck, orange paint marks, cracks and exposed rebar, scaled to ~3.5 m so it does not clip the ceiling. An invisible `SCP173_HitProxy` mesh was added so the centre ray cannot slip between the 120 separate parts.

The real open-source `humanoid.glb` above downloads successfully and is wired up: append `?humanoid=1` to load it (concrete re-skin + 173 paint/neck overlay). It is **not** the default because CesiumMan is a textured, skinned, animated human in a uniform — using it directly would look nothing like a concrete SCP-173 statue, and `SkinnedMesh` raycasting is less reliable for the observation mechanic. `?glb=1` still loads the original procedural `SCP173.glb`. Nothing here is a renamed or faked Sketchfab file.

Freesound preview audio and ambientCG textures are real downloaded open assets. Reuse terms are per-source (Freesound previews carry the individual sound's CC license; ambientCG is CC0; Three.js is MIT).

## Rigged 3D asset upgrade (2026-11-15)

The crude procedural placeholder meshes for the weapon and the creature were replaced with real, open-source, **commercial-use-permitted** rigged GLB models loaded through Three.js `GLTFLoader` + `AnimationMixer`:

- **Weapon (first-person):** `assets/models/FpsRig.glb` — arms + AKM with three skeletal clips `Armature|Idle`, `Armature|Reload`, `Armature|Shoot`. The weapon system is now an **animation state machine**: idle loops; firing plays `Shoot` once; pressing **R** or emptying the 12-round magazine plays the real `Reload` clip, then auto-returns to idle. PBR metalness/roughness on the gun materials were kept from the source (≈0.4 / 0.23–0.82) to read correctly under the scene lighting.
- **Creature (SCP-173):** `assets/models/Xbot.glb` — Three.js official skinned humanoid, re-skinned to a concrete statue and reused as the default monster. Idle/walk/run clips drive the observation chase logic (frozen while watched, walking/running when the centre ray loses line of sight). An invisible `SCP173_HitProxy` keeps the raycast stable.

Both models retain a **procedural fallback**: the game boots instantly with placeholder meshes and seamlessly swaps in the real GLB once it finishes loading, so the experience never blocks on the network.
